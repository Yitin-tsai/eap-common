# eap-common — LLM Context

> Shared library (not a runnable service). All modules depend on this.

## Event Schemas

### OrderSubmittedEvent
```
orderId: UUID, userId: UUID, price: Integer, amount: Integer,
orderType: String ("BUY"|"SELL"), createdAt: LocalDateTime
```

### OrderConfirmedEvent
```
orderId: UUID, userId: UUID, price: Integer, amount: Integer,
orderType: String, createdAt: LocalDateTime
```

### TradeExecutedEvent
```
tradeId: String, sequence: Long, legacyMatchId: Integer,
marketId: String, buyerId: UUID, sellerId: UUID,
buyerOrderId: UUID, sellerOrderId: UUID,
buyerMarketSequence: Long, sellerMarketSequence: Long,
originBuyerPrice: Integer, originSellerPrice: Integer,
dealPrice: Integer, quantity: Integer, occurredAt: LocalDateTime
```

### OrderTradeAppliedEvent / WalletTradeSettledEvent
```
tradeId: String plus downstream completion timestamp/evidence.
Used by MatchEngine completion markers.
```

### OrderFailedEvent
```
orderId: UUID, userId: UUID, reason: String,
failureType: String ("INSUFFICIENT_BALANCE"|"INSUFFICIENT_AMOUNT"|"WALLET_NOT_FOUND"|...),
failedAt: LocalDateTime
```

### OrderCancelEvent
```
orderId: UUID
```
